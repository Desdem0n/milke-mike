# Michal Milke Portfolio

Job-ready portfolio for Michal Milke: a visual product profile combining 3D visualization, website creation, app concepts, front-end interaction work and campaign storytelling.

## Live intent

This site is built to be shared with employers, recruiters and future app or website clients. It presents:

- selected 3D and campaign visuals,
- a cinematic looping hero video,
- the FareScout flight-search app,
- multilingual interface support,
- GitHub repository links,
- a contact form that opens Gmail with a prepared inquiry to `desmilke@gmail.com`.

## Employer and client hook

This portfolio is designed as a fast proof-of-fit: it shows polished visual production, working front-end interaction, multilingual presentation and a product idea in one place. It is intentionally shareable as a hiring profile and as a first contact page for future app or website clients.

Open `index.html` directly in a browser.

## Structure

- `index.html` - portfolio markup
- `styles.css` - responsive visual system
- `script.js` - interactions, filters, sticky notes, language switching
- `assets/work/` - selected portfolio assets and hero video
- `PRD.md` - product requirements and positioning document
